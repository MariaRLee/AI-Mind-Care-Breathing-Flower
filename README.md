# AI-Mind Care 呼吸花開｜Breathing Flower V1.0

## 功能
- 中英雙語
- 1、3、5 分鐘練習
- 三種呼吸節奏
- 花朵開合動畫
- 可開關的柔和提示音
- 練習前／後情緒與放鬆程度紀錄
- 本機瀏覽器保存
- CSV 匯出
- 完成次數、累計分鐘與連續天數
- 手機、平板與電腦響應式版面
- 不使用外部套件、外部字型、分析工具、訪客計數或追蹤程式

## 使用方式
1. 直接開啟 `index.html`。
2. 部署到 GitHub Pages 時，將 `index.html` 放在儲存庫根目錄。
3. 紀錄使用瀏覽器 `localStorage`，不會自動跨裝置同步。
4. 清除瀏覽器資料前，請先用「匯出 CSV」備份。

## 隱私
所有練習紀錄預設只保存在使用者目前瀏覽器。網站本身不會將資料上傳到伺服器。

## 注意
本工具為正念與自我覺察練習，不提供醫療診斷或治療。
