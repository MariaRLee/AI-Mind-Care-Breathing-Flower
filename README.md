## 啟用線上紀錄
V1.2 已包含 Google Sheets / Google Apps Script 的接收程式範例。

1. 建立一份新的 Google Sheet。
2. 在試算表中選擇「擴充功能 → Apps Script」。
3. 將 `google-apps-script.gs` 的內容貼入並儲存。
4. 選擇「部署 → 新增部署 → 網頁應用程式」。
5. 執行身分選擇您自己；存取權依實際測試環境設定。
6. 複製部署後的 `/exec` 網址。
7. 開啟 `config.js`，將網址貼入 `onlineEndpoint`。
8. 重新部署網站。

當 `onlineEndpoint` 留白時，網頁會停用線上儲存選項，但本機紀錄、統計及 CSV 匯出皆可正常使用。

## 隱私
- 線上紀錄採使用者主動勾選同意。
- 請勿要求或輸入真實姓名。
- 不會將「我注意到……」的文字反思傳送到線上。
- 公開靜態網站中的接收端網址可被檢視，因此不應收集敏感或可識別身分的資料。
- 正式大規模使用時，建議改用具有身分驗證、權限管理及刪除機制的後端服務。
