## 呼吸花園
每次完成練習會隨機獲得一朵花：
- 小雛菊
- 薰衣草
- 鬱金香
- 向日葵
- 櫻花
- 玫瑰
- 蓮花
- 扶桑花

「我的花園」包含：
- 今日完成次數
- 累計完成次數
- 最近七天花園
- 溫柔成就徽章
- 最近獲得的花朵
- CSV 匯出與清除紀錄

## 保存欄位
每筆完成紀錄只保存：
- 暱稱（選填）
- 完成日期與時間
- 練習時長
- 獲得的花朵

不保存：
- 練習前後情緒
- 練習前後放鬆程度
- 呼吸循環次數
- 文字反思
- 個人能力分數

## 線上進度備份
線上進度備份不顯示在主畫面。

當 `config.js` 的 `onlineEndpoint` 留白時：
- 線上備份選項完全隱藏
- 本機花園、統計與 CSV 功能正常使用

完成 Google Apps Script 部署並填入 `/exec` 網址後：
- 「我的花園」內才會顯示自願式線上備份選項
- 只傳送暱稱、完成日期時間、練習時長與花朵
- 不傳送其他個人感受資料
